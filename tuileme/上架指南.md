# 浏览器扩展上架指南（Chrome + Edge）

这份指南将手把手教你如何将 **推了么（Tuileme）** 发布到 Chrome Web Store 和 Microsoft Edge Add-ons 商店。

---

## 第一步：准备工作

在上架之前，你需要准备好以下材料：

### 1. 打包扩展文件
你不能直接上传源码，需要上传构建后的 ZIP 包。

**操作步骤：**
1. 在项目根目录运行构建命令：
   ```bash
   npm run build
   ```
   确保 `dist/` 文件夹已生成且包含所有文件。

2. **打包 `dist/` 文件夹**：
   - 进入 `dist/` 文件夹内部。
   - 全选所有文件（`manifest.json`, `assets/`, `content/` 等）。
   - 右键 -> **压缩为 ZIP 文件**（命名为 `tuileme-v1.0.0.zip`）。
   - **注意**：不要把外层的 `dist` 文件夹压缩进去，解压后应该直接看到 `manifest.json`。

### 2. 准备商店素材
两个商店对图片尺寸有严格要求，请提前准备：

| 素材类型 | 尺寸 (px) | 格式 | 说明 |
| :--- | :--- | :--- | :--- |
| **应用图标** | 128 x 128 | PNG | 必须，用于商店展示 |
| **宣传截图** | 1280 x 800 | PNG/JPG | 至少 1 张，建议 3-5 张（展示不同功能） |
| **宣传图 (小)** | 440 x 280 | PNG/JPG | Chrome 必须，Edge 可选 |
| **宣传图 (大)** | 1280 x 800 | PNG/JPG | Chrome 必须，Edge 可选 |

**截图建议**：
1. 一张展示推文页面的“推了么”按钮。
2. 一张展示人格菜单打开的样子。
3. 一张展示悬浮窗（MAGI UI）正在生成的界面。
4. 一张展示选项页配置界面。

### 3. 准备文案
- **标题**：推了么 - AI 智能回复助手
- **短描述**（<132字符）：一键生成 X/Twitter 智能回复，支持多种人格切换，EVA 风格界面。
- **详细描述**：可以使用 `README.md` 的内容，但要去掉开发相关部分，专注于功能介绍。

### 4. 隐私政策（Privacy Policy）
商店必须提供隐私政策 URL。如果你没有网站，可以使用：
- **Notion / Google Docs**：写好后开启“公开分享”，用那个链接。
- **GitHub Gist**：创建一个 md 文件写隐私政策，用 raw 链接。
- **免费生成器**：搜索 "Privacy Policy Generator for Chrome Extension"。

**核心要点**：
- 明确声明：本扩展**不收集**用户数据。
- API Key 仅保存在本地存储（Chrome Storage），不上传到任何服务器。
- 推文内容仅在用户点击生成时发送给 AI 模型服务商（OpenAI），不另作他用。

## 第二步：Chrome Web Store 上架

### 1. 注册开发者账号
1. 访问：[Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/developer/dashboard)
2. 使用 Google 账号登录。
3. **支付注册费**：一次性 **$5 美元**（准备好双币信用卡）。
4. 填写开发者资料（邮箱、名称等）。

### 2. 创建新条目
1. 点击 **"Add new item"**（添加新条目）。
2. 上传你打包好的 `tuileme-v1.0.0.zip`。
3. 系统会自动读取 `manifest.json`。

### 4. 隐私设置 (Privacy) - **最关键的一步，可直接复制**

Chrome 审核非常看重这个部分。以下是根据代码分析后可直接复制的填写内容：

---

#### 单一用途 (Single Purpose)

本扩展的单一用途是：
> **为 X (Twitter) 用户提供 AI 驱动的智能回复生成功能。**

英文版：
> **Provide AI-powered contextual reply generation for X (Twitter) users.**

---

#### 需请求 storage 的理由（直接复制）

```
The extension uses Chrome Storage API to save user preferences locally:
1. API Key (stored in chrome.storage.local for security, never synced)
2. API Base URL, Model name, Max Tokens (user-configurable LLM settings)
3. Persona prompts (custom AI personality templates)
4. UI preferences (language, button label)

All data is stored locally on the user's device. No data is transmitted to our servers.
```

---

#### 需请求主机权限的理由（直接复制）

```
This extension requires host permissions for two purposes:

1. Content Script on x.com/twitter.com:
   - To inject the "Tuileme" reply button into tweet pages
   - To read the current tweet text when user clicks generate (only the specific tweet being replied to)
   - To auto-fill the generated reply into the reply composer

2. Optional broad host permission (https://*/*):
   - The extension connects to OpenAI-compatible LLM APIs
   - Users can configure custom API endpoints (e.g., enterprise proxies, self-hosted models, regional mirrors)
   - Since we cannot predict which domains users will configure, we request optional broad permissions
   - This permission is OPTIONAL and only requested when the user actually needs to connect to a custom endpoint
```

---

#### 您正在使用远程代码吗？

选择：**不，我并未使用远程代码**

理由（如果要求填写）：
```
All JavaScript code is bundled and included in the extension package. No external scripts are loaded via CDN, <script src>, or dynamic import from remote URLs. No eval() or new Function() is used.
```

#### 数据使用 - 应该勾选哪些？

根据代码分析，你需要勾选：

| 数据类型 | 是否勾选 | 原因 |
|---------|---------|------|
| 个人身份信息 | ❌ 不勾选 | 不收集姓名、邮箱等 |
| 健康信息 | ❌ 不勾选 | 不涉及 |
| 财务和付款信息 | ❌ 不勾选 | 不涉及 |
| 身份验证信息 | ✅ **勾选** | 用户需要填写 API Key（属于凭证类） |
| 个人通讯 | ❌ 不勾选 | 不收集邮件/短信 |
| 位置 | ❌ 不勾选 | 不涉及 |
| 网络记录 | ❌ 不勾选 | 不记录浏览历史 |
| 用户活动 | ❌ 不勾选 | 不监控点击/滚动等 |
| 网站内容 | ✅ **勾选** | 读取推文文本用于生成回复 |

**重要说明（填在补充说明里）**：
```
1. Authentication Info (API Key):
   - User's API Key is stored ONLY in chrome.storage.local (never synced)
   - The key is sent directly to the user-configured LLM API endpoint
   - We do not have access to or store user API keys on any server

2. Website Content (Tweet Text):
   - We read the text content of the specific tweet the user wants to reply to
   - This text is sent to the user-configured LLM API to generate a contextual reply
   - We do not store, log, or transmit tweet content anywhere else
```

Last updated: 2025-01-27

## Overview
推了么 (Tuileme) is a browser extension that helps users generate AI-powered replies on X (Twitter). We are committed to protecting your privacy.

## 避坑指南（审核通过秘籍）

### 1. 权限最小化原则
`manifest.json` 里的 `permissions` 和 `host_permissions` 越少越好。
- 目前你的配置是合理的（`storage` + `optional_host_permissions`）。
- **不要**加 `tabs`, `cookies` 等不需要的权限，否则会被拒或要求详细解释。

### 2. 描述不要夸大
- 不要说“全网最强”、“破解 X 限制”等。
- 实事求是：Assistant for X/Twitter。

### 3. 这里的坑：Host Permissions 解释
Chrome 会问你为什么需要 `https://*/*`。
**标准话术**：
> "The extension connects to LLM APIs (like OpenAI). Users can configure their own custom API endpoints (e.g., local proxies or enterprise gateways) which can be any URL. Therefore, we cannot whitelist specific domains in advance and need broad host permissions to support user-defined API bases."

### 4. 这里的坑：单一用途 (Single Purpose)
扩展必须专注于一个功能。
- 你的功能很聚焦（AI 回复），这没问题。
- 不要把不相关的功能（如“天气预报”、“汇率转换”）塞进去。

### 5. 版权问题
- 描述里提到 X/Twitter 时，必须表明 **"unofficial"** 或 **"no affiliation"**。
- 图标**绝对不能**直接用 X 或 Twitter 的官方 LOGO（会被秒拒）。你现在的自定义图标是安全的。
